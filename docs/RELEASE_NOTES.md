FormSeed's first preview release includes local mock-data generation, smart field detection, native controls, framework events, custom rules, site profiles, import/export, repeatable seeds, and native-field undo.

Download the ZIP matching your browser. Chrome/Edge/Opera packages can be loaded unpacked for development. Firefox needs AMO signing for permanent public installation. Safari's ZIP contains resources for Apple's web extension packager; it is not a signed app.

See README.md for installation and docs/PUBLISHING.md for marketplace submission steps. See docs/TESTING.md for verified behavior and remaining platform checks. This preview has not been approved or listed by browser marketplaces.
