## Full description

FormSeed helps developers and QA teams fill web forms with realistic synthetic data in a click. Spend less time typing test values into signup, checkout, admin, and staging forms.

Fill a whole page, the focused form, or one chosen field. Smart detection uses field types, labels, autocomplete, and names to generate appropriate names, emails, phone numbers, passwords, addresses, dates, and numbers.

Customize business-specific fields with fixed values, generators, digit lengths, numeric ranges, and pattern templates. Create site profiles, pause filling on individual sites, and export/import settings for repeatable team workflows. A seed helps reproduce the same test data.

Existing values are preserved by default. Hidden, disabled, read-only, CAPTCHA/honeypot, file, and button fields are skipped. Undo restores the last native-field fill while preserving subsequent manual edits. FormSeed never submits a form.

All generation happens locally. No account, analytics, tracking, remote generation API, or remote executable code. Preferences and rules use local browser storage.

Native forms and representative React, Vue, and Angular forms are supported, with an adapter for compatible React Select / ARIA listbox dropdowns. Browser-protected pages, inaccessible frames, closed shadow roots, and unsupported custom components are outside the extension's reach. Websites may react to normal field-change events under their own privacy policies.

Free and open source. Source, documentation, and support: https://github.com/prasanth1308/mock-fill-extension

## Reviewer instructions

No account or credentials are needed. Build the source with the commands in README.md. Run `npm run demo` and visit `http://127.0.0.1:4173/demo/`, or use a normal page with a standard form. Click the FormSeed toolbar button → Fill this page. Inspect native fields and framework-state outputs. Confirm that protected fields remain untouched and the form is not submitted. Undo the fill. Add a rule for `employeeId` using the fixed value `EMP-0042` and fill again.

The default keyboard command is Alt+Shift+F (Option+Shift+F on Mac), subject to browser/OS shortcut assignment. On first context-menu use, Chrome may request an extra click to select the exact field. The Safari ZIP contains web-extension resources and needs Apple packaging.
